# Borozdov Copybook

A theme from the Borozdov collection. Two faces — light **Chalkline**, an open notebook in
classroom morning light, and dark **Nightclass**, the same page under a desk lamp after
hours. Hairline-ruled cards, three tiers of grey ink, and a single confident blue for
every interactive moment.

![Borozdov Copybook in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/copybook/main/screenshots/light.png)

![Borozdov Copybook in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/copybook/main/screenshots/dark.png)

## Principles

- **One accent, spent carefully.** Blue lives on links, active states and the one filled
  button — never on a background fill, never as decoration. Everywhere else is grey.
- **Three tiers of grey ink.** Ink for running text, muted for secondary, faint for
  tertiary — the same three steps from headings down to a table's footnote row.
- **A hairline rules every card.** Callouts, code panes, tables and popovers share one
  card language: a margin fill and a 1px hairline rim at 12px corners, never a shadow.
- **The page stays the brightest surface.** On Chalkline the editor is true white against
  an off-white margin; on Nightclass the roles hold, just inverted, so the note itself
  never recedes behind its own chrome.
- **Developer-native type.** The platform's own sans at 400 for text and 600 for
  headings — no embedded font, no load, no flash of unstyled text.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts, code blocks, tables and popovers drawn as the same hairline-rimmed card
- Tags and property pills as flat, square badges that pick up the accent under the pointer
- A pill-shaped call-to-action button, the one place the theme's shape changes
- Quiet editing: no focus ring around the note or its title while you type; property
  names read as labels, not boxed fields
- A toggle thumb tuned per face so it never disappears against its own track
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 13 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Copybook**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/copybook/releases/latest)
into `<vault>/.obsidian/themes/Borozdov Copybook/`, then choose Borozdov Copybook under
Settings → Appearance → Themes.
